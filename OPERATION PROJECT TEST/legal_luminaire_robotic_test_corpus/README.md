# Legal Luminaire Robotic User Test Corpus

## PURPOSE
This archive contains entirely synthetic, fictional documents for automated and robotic user testing of Legal Luminaire.

DO NOT treat any person, case, FIR number, phone number, address, authority, citation, statutory proposition, deadline, or legal conclusion in this corpus as real or reliable.

The corpus is designed to test:
- document ingestion
- drafting from documents
- draft vetting
- draft enrichment
- opponent-document analysis
- chronology extraction
- contradiction detection
- limitation/deadline workflows
- citation verification
- hallucination resistance
- PII redaction
- bilingual/Hinglish handling
- OCR/scanned-document workflows
- prompt injection resistance
- export safety
- beginner/intermediate/advanced user journeys

## DIRECTORY INDEX
See `INDEX.md` for the full inventory and `TEST_SCENARIOS.md` for suggested robotic-user tasks.

## IMPORTANT
Several documents intentionally contain:
- contradictory facts
- fake citations
- malformed citations
- fictional case names
- wrong dates
- unsupported assertions
- old/new statute confusion
- PII-like dummy values
- prompt-injection text
- missing pages or missing facts

These are intentional test fixtures.
