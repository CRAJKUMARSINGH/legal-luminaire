# Daily working rhythm (recovery month)

Use every work day. Times are local.

## Morning recovery sync — 15 minutes

1. Overnight incidents, broken builds, blocked deploys
2. Top 3 risks from yesterday (`BOARD.md`)
3. Which modules are touched today
4. Owner for each active change
5. Does any change introduce a new pattern or exception?

## Midday review — 10–15 minutes

1. CI state
2. High-risk PRs
3. Confirm no uncontrolled merge
4. Escalate ownership gaps

## End-of-day close — 15 minutes

1. What was standardized today
2. Decisions made (ADR or handbook note if architectural)
3. Update `BOARD.md`
4. Tomorrow’s focus
5. Any bypass? If yes, exception register row
