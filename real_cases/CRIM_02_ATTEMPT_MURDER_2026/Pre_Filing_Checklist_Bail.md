# Pre-Filing Checklist – Bail Application

- [ ] All prosecution documents (FIR, Chargesheet, Medical report) reviewed
- [ ] Evidence Matrix completed with Fact-Fit scores
- [ ] Verification tiers assigned
- [ ] Medical injury certificate analyzed
- [ ] Self-defence claim prepared with supporting evidence
- [ ] Case law on Section 307 BNS verified
- [ ] Antecedent verification completed
- [ ] Bilingual versions prepared
- [ ] Verification Report attached
- [ ] Client final approval taken
- [ ] Court fees verified
- [ ] Bail bond documents prepared
