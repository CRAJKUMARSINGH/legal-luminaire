# Pre-Filing Checklist – Bail Application (POCSO Case)

- [ ] All prosecution documents (FIR, Chargesheet, Medical report) reviewed
- [ ] Evidence Matrix completed with Fact-Fit scores
- [ ] Verification tiers assigned
- [ ] Age determination documents analyzed thoroughly
- [ ] School certificate examined for authenticity
- [ ] Ossification test report analyzed
- [ ] Birth certificate status verified
- [ ] POCSO Act provisions complied with
- [ ] Mandatory reporting compliance verified
- [ ] Case law on POCSO bail verified
- [ ] Antecedent verification completed
- [ ] Bilingual versions prepared
- [ ] Verification Report attached
- [ ] Client final approval taken
- [ ] Court fees verified
- [ ] Special conditions for POCSO bail considered
