# Pre-Filing Checklist – Discharge Application

- [ ] All prosecution documents (FIR, Chargesheet, PM, Call records) reviewed
- [ ] Evidence Matrix completed with Fact-Fit scores
- [ ] Verification tiers assigned
- [ ] PENDING and FATAL_ERROR items blocked from draft
- [ ] Conspiracy evidence analyzed thoroughly
- [ ] Call record analysis completed
- [ ] Case law on Section 120B BNS verified
- [ ] Case law on conspiracy discharge verified
- [ ] Bilingual versions prepared
- [ ] Verification Report attached
- [ ] Client final approval taken
- [ ] Court fees verified
- [ ] Separate discharge applications for each accused prepared
