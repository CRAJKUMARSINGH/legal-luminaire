# Annex B — BNSS / BSA Mapping

BNSS 2023 and BSA 2023 are in force. Plead the new section; keep the old one in
brackets for transition. Mappings below are the ones this corpus uses.

**Status key:** V = verified mapping · S = secondary, confirm wording · P =
pending, do not plead without a source.

## Rules for using this table

1. Never swap a number without keeping the old one in brackets in a draft.
2. A mapping is not a holding. You still need the provision's own text.
3. Where a 2023 or 2024 incident straddles commencement, check which Code
   governs before pleading anything.
4. Rajasthan state Acts are untouched by the 2023 codes. s. 207 of the Tenancy
   Act is still s. 207.
