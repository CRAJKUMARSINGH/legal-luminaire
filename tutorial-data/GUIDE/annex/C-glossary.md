# Annex C — Glossary

Terms that appear at district counters. Hindi/Hinglish usage is how clients
actually speak; the right column is how it goes in a draft.

| Counter usage | What it means | Draft language |
|---|---|---|
| jamabandi | Record of rights; not title | "record of rights" |
| khasra | Plot number in the field register | "khasra no. ___" |
| naksha | Field map / site plan | "naksha / site plan" |
| girdawari | Crop and possession inspection entry | "khasra girdawari" |
| kabza | Encroachment / possession taken | "encroachment", "dispossession" |
| khatedar | Tenant with heritable, transferable rights | "khatedar tenant" |
| samjhauta | Compromise | "compromise" |
| vakalatnama | Authority to appear | "vakalatnama" |
| no objection | Predecessor's clearance | "no-objection" |
| tahrir | Written complaint | "written report" |
| parcha | Slip / order sheet entry | "order sheet" |
| mukadma | Case | "case", "suit", "proceeding" |
| peshi | Appearance date | "date of hearing" |
| stay | Interim order | "interim injunction" (civil), "stay" (execution) |
| thaga | Cheated (client's word) | "cheating" only if the elements are pleaded |
| jhagda | Dispute | "dispute" |
| taqseem | Partition | "partition" |

## Two traps

**"Thaga" is not a cause of action.** Clients use it for every disappointment.
Decide whether the elements of cheating exist before writing the word.

**"Stay" is two different things.** An injunction restrains a party; a stay
suspends execution. Beginners use them interchangeably and get the application
wrong.
