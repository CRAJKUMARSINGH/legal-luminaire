# Annex F — Trap Index

Facilitator copy. Ordered by week, so it reads as a plan rather than an appendix.

**How to use it**

- Read the week's block before you run the week.
- The **symptom** column is what to look for in the trainee's own words. It is
  specific on purpose. "Wrong forum" is not a symptom; "civil court named
  because the tehsildar said so" is.
- The **counter-move** is what you say in session 3, after the reveal, and only
  if the trainee missed it themselves.
- Do not read the counter-move aloud before session 1. It is the answer.

Pair IDs are written in full (`TP-RJ-01`) so the validator can trace every pair
to a row here. If you add a pair, add the row, or the build breaks.

## Traps no pair can carry

These are real and the corpus does not simulate them. Say so out loud rather
than letting a band 4 imply otherwise.

- **The counter.** Every pair is a document. A trainee can score band 4 across
  eleven weeks and freeze when a client starts crying at the counter.
- **The corridor.** POCSO pairs teach the room, not the ten minutes before it.
- **The colleague.** No pair has an opponent who is a friend, or a clerk who is
  a relative.
- **The fee conversation.** TP-RJ-08 touches a dispute, no pair has the first
  fee discussion.
- **The wrong client.** Every intake here is honest. None is lying to the
  advocate.

## Traps that are unverified on purpose

- **TP-RJ-13, TP-RJ-14, TP-RJ-16, TP-RJ-24** — the revenue appeal and evidence
  provisions are `PENDING` in every one. A facilitator who teaches the ladder
  from memory will get a rung wrong.
- **TP-RJ-18** — the BSA numbering for examination is `PENDING`. Do not let a
  trainee write a section number they have not opened.
- **TP-RJ-22** — the transitional provision question is open. "2013 obviously
  applies" is not an answer.
- **TP-RJ-23** — the maintainability point is `PENDING`. A facilitator who says
  "file an appeal" teaches the exact error the pair exists to catch.

If a cohort falls into fewer than half of a week's traps, the week needs a
sharper cold prompt, not a longer session 3.
